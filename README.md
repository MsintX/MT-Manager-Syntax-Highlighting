# MT Manager Syntax Highlighting

为 "MT 管理器（MT Manager）" (https://mt2.cn/) 提供额外的语法高亮配置  
  
本项目目前包含 F# 与 XAML 的语法高亮规则，旨在让你在 MT 管理器中查看和编辑相关代码时，获得更清晰的语法着色效果  
  
## 使用方法

1. 下载本仓库中对应的 ".mtsx" 配置文件  
2. 根据 MT 管理器对应版本提供的语法高亮导入方式，导入配置文件    
3. 打开对应类型的文件，检查语法高亮效果  
  
如果配置无法导入或部分语法显示不正确，请确认 MT 管理器版本及配置文件的兼容性
